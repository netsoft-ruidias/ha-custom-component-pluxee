# Pluxee Benefits Integration

Pluxee Benefits - Custom Component for Home Assistant

Current major version: **v1**

The data source for this integration is the [Pluxee Consumer Portal](https://consumidores.pluxee.pt/).

The author of this project categorically rejects any and all responsibility for the card balance and other data that were presented by the integration.

# Installation

## HACS (Recommended)

This integration can be added to HACS as a custom (non-default) repository.

Assuming you have already installed and configured HACS, follow these steps:

1. Navigate to the HACS integrations page
2. Choose Integrations under HACS
3. Click the '+' button on the bottom of the page
4. Search for "Pluxee", choose it, and click install in HACS
5. Ready! Now continue with the configuration.

## Configuration Through the interface

1. Navigate to `Settings > Devices & Services` and then click `Add Integration`
2. Search for `pluxee`
3. Enter your credentials:
   - **NIF** (Portuguese Tax ID - 9 digits)
   - **Password**
4. The integration will connect to the Pluxee portal and retrieve your card data
5. Repeat the procedure as many times as desired to include other cards/accounts you may have

### Notes for v1

- Authentication uses NIF (Portuguese Tax Identification Number) instead of email.
- No OTP/2FA verification is required.
- Data is updated every 30 minutes.
- The integration can request re-authentication when the session expires.

# Presentation

The Pluxee meal balance is exposed as a dedicated monetary sensor entity.

To present your data (card balance), use any entity card with your meal sensor.

Entity IDs are generated by Home Assistant from your NIF. Example:

```yaml
type: entities
entities:
  - sensor.pluxee_214214389_meal
```

## Transactions

While showing the card's balance on a card is commonplace (any entity card will do), displaying transactions can be more complicated to achieve.

We recommend using [custom:list-card](https://github.com/iantrich/list-card) which has the advantage of being able to indicate the number of rows to display:

```yaml
type: custom:list-card
entity: sensor.pluxee_214214389_meal
feed_attribute: transactions
title: My Pluxee Transactions
row_limit: 10
columns:
  - title: Data
    field: date
  - title: Movimento
    field: description
  - title: Valor
    field: amount
    postfix: " €"
    style:
      - text-align: right
      - white-space: nowrap
```

Each transaction includes these fields:

- `date`
- `description`
- `amount`
- `currency`

By default, the integration keeps up to 20 transactions per card.

## Manual Refresh Service

You can manually trigger a data refresh using the `pluxee.refresh` service:

```yaml
service: pluxee.refresh
```

Or for a specific integration entry:

```yaml
service: pluxee.refresh
data:
  config_entry_id: "your_config_entry_id_here"
```
